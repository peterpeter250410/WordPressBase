# 日本留学中介平台 — 产品功能清单

> 文档版本：v1.0
> 更新日期：2026-07-16
> 阅读对象：开发团队内部

---

## 优先级说明

| 标记 | 含义 |
|-----|------|
| **P0** | MVP 必须，核心业务流程闭环所需 |
| **P1** | 重要，提升体验/运营效率，紧随 MVP |
| **P2** | 增强/后续迭代 |

---

## 模块总览

```
留学中介平台
├── A. 官网展示模块           (对外品牌与引流)
├── B. 学生账号模块           (注册/登录/个人中心)
├── C. 基础信息采集模块       (匹配条件表单)
├── D. 院校库模块             (数据管理 + 展示)
├── E. 自动匹配引擎模块       (核心算法)
├── F. 推荐与选校模块         (结果推送 + 选校)
├── G. 申请资料模块           (上传 + 加密存储)
├── H. 顾问/管理后台模块      (分级权限管理)
├── I. 通知与沟通模块         (站内/邮件)
├── J. 多语言模块             (语种扩展)
└── K. 安全与合规模块         (加密/权限/日志)
```

## C. 基础信息采集模块

| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| C-01 | 基础信息表单 | P0 | 匹配核心字段：**预算、意向专业**（必填） |

| C-04 | 表单校验 | P0 | 必填校验、格式校验、数值范围校验 |
| C-05 | 草稿保存 | P1 | 未提交可保存草稿，下次继续 |
| C-06 | 信息编辑与重新匹配 | P1 | 修改信息后可触发重新匹配 |

> 匹配字段设计详见 `MATCHING-ALGORITHM.md`。字段可配置，新增字段不改表单框架。

## E. 自动匹配引擎模块

| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| E-01 | 匹配触发 | P0 | 学生提交/更新基础信息后自动触发 |
| E-02 | 预算匹配 | P0 | 学生预算落入院校学费区间的判断与评分 |
| E-03 | 专业匹配 | P0 | 学生意向专业与院校专业标签匹配评分 |

## MVP 范围汇总（P0 功能）

MVP 需闭环以下最小功能集：

1. **官网**：首页、服务、联系、院校公开展示（A-01/02/04/06）
2. **账号**：注册、登录、找回密码、个人中心（B-01~04）
3. **信息采集**：基础信息表单（预算+专业）、校验（C-01/04）
4. **院校库**：数据模型、后台管理、专业子项、详情展示、匹配字段（D-01/02/03/05/06）
5. **匹配引擎**：触发、预算匹配、专业匹配、评分排序（E-01~04）
6. **推荐选校**：结果展示、推送、选校、触发资料提交（F-01/02/04/06）
7. **资料提交**：清单、上传、加密存储、校验、受控下载（G-01/02/03/04/07）
8. **后台**：学生列表分级、详情、资料审核（H-01/02/03）
9. **通知**：站内 + 邮件（I-01/02）
10. **多语言底座**：架构、切换器、界面 i18n（J-01/02/03）
11. **安全合规**：加密、权限分级、同意书、HTTPS、防越权、基础加固（K-01/02/03/06/07/08）
